# Art Gallery App

**Студент:** Носова Алина Андреевна  
**Группа:** Б9123-09.03.02 ацс

## Описание

Персонализированное offline-first приложение для просмотра коллекции произведений искусства Chicago Art Institute. Реализованы коллекции, заметки, история просмотров, настройки темы/TTL/автосинхронизации, кэширование с Room, фоновая синхронизация через WorkManager.

## Стек

- Kotlin + Jetpack Compose
- Room (кэш, коллекции, заметки, история)
- DataStore (настройки)
- Hilt (DI)
- WorkManager (фоновая синхронизация)
- MockK + Turbine (тесты)

## Сборка и тесты

./gradlew testDebugUnitTest
